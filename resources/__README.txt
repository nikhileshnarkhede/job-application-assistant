# Resources Folder

This folder contains compliance resources for resume and cover letter validation.

## Required Files

1. **Action_Verbs.xlsx** - Excel file with action verbs by category
2. **Resume Checklist.txt** - Checklist items for resume validation
3. **Resume guide.txt** - Guide for resume writing best practices
4. **Resume rubric.xlsx** - Scoring rubric for resume evaluation
5. **Cover Letter Checklist.txt** - Checklist items for cover letter validation
6. **Cover letter guide.txt** - Guide for cover letter writing
7. **Cover letter rubric.xlsx** - Scoring rubric for cover letter evaluation

## File Formats

### Action_Verbs.xlsx
Columns should be verb categories (e.g., Leadership, Technical, Analysis)
Rows should be individual verbs

### Checklist Files (.txt)
One checklist item per line

### Guide Files (.txt)
Free-form text with best practices and examples

### Rubric Files (.xlsx)
Columns: Category, Weight, Criteria, Excellent, Good, Needs Improvement
