================================================================================
INSTRUCTIONS
================================================================================

Option 1: MANUAL ENTRY (Recommended for accuracy)
- Fill in each project section below with your actual project details
- Include: name, description, tech stack, key features, metrics

Option 2: LOCAL REPO SCAN
- Set GITHUB_REPOS_PATH in .env to your repos folder
- System will scan README.md files and detect tech from code

Option 3: GITHUB API
- Set GITHUB_USERNAME in .env
- System will fetch public repos via API
