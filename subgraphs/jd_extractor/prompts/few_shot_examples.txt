## Usage Notes

1. **Consistency**: Always extract in the same format shown above
2. **Keywords**: Include all technical terms, tools, frameworks - they're critical for ATS
3. **Role Type**: Classify based on primary job function, not just title
4. **Confidence**: Lower confidence if JD is vague, poorly written, or missing key information
5. **Null values**: Use null (not "N/A" or "Not specified") for missing optional fields
6. **Lists**: Use empty lists [] for missing list fields, never null for lists
