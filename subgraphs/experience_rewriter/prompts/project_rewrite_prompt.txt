## Rewriting Requirements

1. **ADD METRICS** - Every bullet needs quantifiable impact:
   - Performance: "achieving 92% accuracy", "reducing latency by 60%"
   - Scale: "processing 10K+ documents", "handling 1000 req/sec"
   - Improvement: "3x faster inference", "40% reduction in errors"

2. **ACTION VERBS** - Start each with:
   - Built, Developed, Engineered, Architected, Designed
   - Implemented, Deployed, Integrated, Optimized
   - Created, Pioneered, Established

3. **KEYWORD INTEGRATION** - Naturally include:
   - Technologies from tech stack
   - Target keywords from JD
   - Technical methodologies

4. **SHOW VALUE** - End with impact:
   - "enabling real-time insights"
   - "reducing manual effort by 50%"
   - "improving user experience"

## Output Format

Return ONLY the rewritten bullets:

REWRITTEN_BULLETS:
- [First bullet with metric]
- [Second bullet with metric]
- [Third bullet with metric]

KEYWORDS_USED:
[keywords incorporated]

## Example

Original: "Built a RAG system for document Q&A"
