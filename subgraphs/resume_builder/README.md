# Resume Builder Subgraph

Assembles the complete ResumeJSON from rewritten content.

## Overview

The Resume Builder subgraph combines all resume components into a structured JSON format:
- JD-tailored professional summary (LLM generated)
- Reordered skills by JD relevance
- Formatted experiences and projects
- Education, certifications, publications

## Graph Flow

```
START ──► load_candidate_data ──► tailor_summary ──► optimize_skills
                                                          │
                                                          ▼
                        END ◄── assemble_resume ◄── format_projects ◄── format_experiences
```

## Usage

```python
from subgraphs import build_resume, build_general_resume, resume_to_dict

# With structured JD (tailored)
result = build_resume(
    structured_jd=jd,
    rewritten_experiences=experiences,
    rewritten_projects=projects,
    skill_match_result=skill_match
)
resume = result["resume_json"]

# General resume (no JD tailoring)
result = build_general_resume(
    rewritten_experiences=experiences,
    rewritten_projects=projects
)

# Convert to dict for serialization
resume_dict = resume_to_dict(result["resume_json"])
```

## Files

| File | Description |
|------|-------------|
| `__init__.py` | Package exports |
| `state.py` | ResumeBuilderState definition |
| `nodes.py` | Node functions |
| `graph.py` | Graph builder and convenience functions |
| `prompts/` | LLM prompts for summary generation |
| `test.py` | Test script |

## Convenience Functions

| Function | Description |
|----------|-------------|
| `build_resume(structured_jd, rewritten_experiences, rewritten_projects, skill_match_result)` | Full build with JD |
| `build_general_resume(rewritten_experiences, rewritten_projects)` | Build without JD tailoring |
| `resume_to_dict(resume_json)` | Convert ResumeJSON to dict |

## Return Value

```python
{
    "resume_json": ResumeJSON,      # Complete resume
    "tailored_summary": str,         # Generated summary
    "optimized_skills": dict,        # Reordered skills
    "error": str | None,
    "build_complete": bool
}
```

## Summary Generation

The professional summary is generated by LLM considering:
- JD requirements and keywords
- Candidate's top skills and experiences
- Target word count (40-60 words)
- Action-oriented language

## Skill Optimization

Skills are reordered by:
1. Required skills from JD (first)
2. Preferred skills from JD
3. Other relevant skills
4. Additional skills
