## YOUR TASK

Generate EXACTLY {num_suggestions} suggestions following these rules:

### RULE 1: Target HIGH PRIORITY First
- At least 70% of suggestions must target 🔴 HIGH PRIORITY keywords
- These are required skills - missing them = automatic rejection

### RULE 2: Be Extremely Specific
For each suggestion, provide:
- The EXACT original text
- The EXACT modified text
- No vague advice like "consider adding" - give the actual text

### RULE 3: Make Keywords Fit Naturally
BAD: "Used Python and Java and C++ and algorithms"
GOOD: "Engineered high-performance Python and Java applications leveraging advanced algorithms and data structures for distributed computing"

### RULE 4: One Suggestion Can Add Multiple Keywords
If keywords are related, combine them naturally:
- "algorithms" + "data structures" → "...optimized algorithms and data structures..."
- "distributed computing" + "parallel computing" → "...distributed and parallel computing systems..."

### RULE 5: Fix Format Issues in Suggestions
If a bullet has pronouns or is too long, fix that too while adding keywords.
