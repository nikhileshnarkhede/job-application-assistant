# Few-Shot Examples for Skill Gap Analysis

## Example 1: High Match (92%)

### Input:
- JD Required: Python, TensorFlow, Machine Learning, SQL, Docker
- JD Preferred: Kubernetes, AWS, MLOps
- Matched: Python, TensorFlow, Machine Learning, SQL, Docker, AWS
- Missing: Kubernetes, MLOps
- Match: 92%

### Analysis:
Strong alignment with 92% skill match covering all required skills. The candidate's AWS experience partially addresses the cloud/DevOps gaps. Resume should prominently feature the matched technical stack while mentioning any container orchestration exposure to bridge the Kubernetes gap.

## Example 2: Good Match (75%)

### Input:
- JD Required: Python, PyTorch, NLP, Transformers, AWS
- JD Preferred: LangChain, RAG, Vector Databases
- Matched: Python, NLP, Transformers, AWS
- Missing: PyTorch, LangChain, RAG, Vector Databases
- Match: 75%

### Analysis:
Good foundational match at 75%, with the PyTorch gap being bridgeable if the candidate has TensorFlow experience (frameworks are transferable). The LLM-specific skills (LangChain, RAG) are emerging technologies where demonstrated NLP expertise and quick learning ability should be emphasized. Consider highlighting any relevant projects involving embeddings or semantic search.

## Example 3: Moderate Match (58%)

### Input:
- JD Required: Java, Spring Boot, Microservices, Kafka, PostgreSQL
- JD Preferred: Docker, Kubernetes, AWS
- Matched: PostgreSQL, Docker, AWS
- Missing: Java, Spring Boot, Microservices, Kafka
- Match: 58%

### Analysis:
Moderate alignment at 58% with significant gaps in core Java ecosystem skills. Unless the candidate has strong Java experience not captured in their profile, this role may be a stretch. The infrastructure skills (Docker, AWS, PostgreSQL) are valuable but secondary to the missing backend development requirements.

## Example 4: Low Match with Transferable Skills (45%)

### Input:
- JD Required: Scala, Spark, Airflow, Data Engineering, AWS
- JD Preferred: Kafka, Delta Lake, DBT
- Matched: AWS, Python (related to Spark/Airflow)
- Missing: Scala, Spark, Airflow, Data Engineering, Kafka, Delta Lake, DBT
- Match: 45%

### Analysis:
Low direct match at 45%, but if the candidate has strong Python data processing experience, the transition to Scala/Spark is feasible. The role requires a data engineering mindset which may be partially demonstrated through Python-based ETL work. Recommend highlighting any pipeline development, batch processing, or data transformation projects to bridge the gap.

## Example 10: Entry-Level ML Role (78%)
